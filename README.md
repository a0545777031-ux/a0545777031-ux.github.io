# دفتر الإيجارات

تطبيق ويب لإدارة إيجارات الغرف والمحلات — يعمل من اللابتوب والجوال، والبيانات مشتركة سحابياً بين المالك والمتابع.

## الأدوار

| | المالك / المدير | المتابع |
|---|---|---|
| إدخال الوحدات والمستأجرين والعقود والمصروفات | ✅ | ✅ |
| تسجيل السداد | ✅ | ✅ |
| اعتماد السجل (قفله) | ✅ | ✅ |
| تعديل سجل معتمد | ✅ | بعد موافقة المالك |
| الحذف، الإعدادات، سجل النشاط | ✅ | ❌ |

## التشغيل

1. أنشئ مشروعاً مجانياً في [supabase.com](https://supabase.com).
2. من **SQL Editor** شغّل محتوى `schema.sql`.
3. من **Project Settings → API** انسخ `Project URL` و `anon public key` وضعهما في `config.js`.
4. فعّل **GitHub Pages** من: Settings → Pages → Branch: `main` / root.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملاً (واجهة + منطق) |
| `config.js` | مفاتيح الاتصال بـ Supabase |
| `schema.sql` | إنشاء الجدول وسياسات الوصول |
| `manifest.json` | تثبيت التطبيق على الجوال كأيقونة |

## ملاحظات

- توثيق العقود نظامياً يتم عبر منصة **إيجار**، والفوترة الإلكترونية عبر **زاتكا**. هذا السجل للإدارة والمتابعة الداخلية.
- رمزا الدخول (المدير/المتابع) يُحفظان في قاعدة البيانات ويفصلان الصلاحيات داخل الواجهة. من يعرف رابط المشروع ومفتاح `anon` يستطيع تقنياً قراءة البيانات — للحماية الكاملة تُفعّل مصادقة Supabase لاحقاً.
